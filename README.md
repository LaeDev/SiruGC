# 시루 그룹챗

하나의 방에서 채팅, 유튜브 같이 보기(대기열), 화면 공유, 음성 대화, 쪽지를 할 수 있는 웹앱입니다. 방에는 닉네임·아바타·내 색만 정하면 게스트로 들어올 수 있고, **쪽지는 가입한(로그인한) 사람끼리만** 주고받습니다.

## 시작하기

| 환경 | 방법 |
|---|---|
| Windows | `start-windows.bat` 더블클릭 (터미널에서는 `.\start-windows.bat`) |
| Linux / macOS | `./start-linux.sh` (실행 권한이 없으면 `chmod +x start-linux.sh`) |
| 직접 | `npm install` 후 `npm start` |

Node.js 18 이상이 필요합니다. 켜면 접속 주소가 나옵니다(`http://localhost:3000`). 끄려면 Ctrl+C — 접속자 화면에는 "서버가 꺼졌습니다" 안내가 바로 뜹니다.

## 설정 (`config.env`)

`config.example.env`를 `config.env`로 복사해서 필요한 줄만 켜세요. `config.env`는 git에 올라가지 않습니다(비밀번호를 여기에 두세요).

- `TRUST_PROXY=1`, `HOST=0.0.0.0` — NPM/nginx 같은 프록시 뒤에서 https로 공개할 때. 프록시는 Scheme을 `http`, **Websockets Support를 켜기**.
- `ICE_SERVERS` 또는 `TURN_URL`+`TURN_SECRET` — 집 밖 네트워크에서 화면 공유·음성이 안 보일 때(TURN 중계 서버).
- `UPLOAD_*` — 사진·동영상 업로드의 크기·보관 기간 한도(기본: 사진 12MB, 동영상 80MB, 30일, 서버 전체 2GB). 파일은 `uploads/`에 저장돼요.
  **NPM/nginx 뒤라면** 프록시도 큰 파일을 받게 해야 해요: NPM의 프록시 호스트 → Advanced에 `client_max_body_size 100m;` 을 넣으세요. 안 넣으면 큰 파일이 413 오류로 올라가지 않아요.
- `RESUME_GRACE_MS`, `RESUME_GRACE_MOBILE_MS` — 연결이 끊긴 사람을 방에 남겨 두는 시간. **폰·태블릿은 화면이 꺼져도 기본 10분 동안 "자리 비움"으로 남아요**(PC는 1분). 돌아오면 같은 자리를 이어받고, 앱이 완전히 닫혔다가 알림을 눌러 다시 열려도 같은 자리를 써요. 음성·화면 공유는 1분 넘게 끊기면 정리돼요(방에는 남음).
- 닉네임은 방에서 겹칠 수 없고(게스트가 계정의 닉네임을 쓸 수도 없고)(대소문자·공백·`_ - .` 차이는 같은 이름으로 봄), 한글·영문·숫자·공백·`_ - .` 만 쓸 수 있어요. IP나 닉네임이 같다는 이유로 다른 사람의 쪽지·프로필을 함께 쓰게 하지는 않아요.
- `PROXY_IP` — 프록시(NPM)가 다른 기기에 있어서 이 서버 포트가 LAN에서 열려 있을 때, 그 프록시의 IP(쉼표로 여러 개). 정하면 그 주소에서 온 연결의 `X-Forwarded-*`만 믿어요. 안 정하면 `TRUST_PROXY`일 때 누가 보내든 믿어서, 직접 접속한 사람이 IP·주소·https 표시를 위조해 로그인 횟수 제한과 https 강제를 피할 수 있으니 **방화벽으로 프록시만 들어오게 하거나 `PROXY_IP`를 정하세요.**
- `AUTH_HOST`, `SIGNUP_CODE`, `ADMIN_NAME`/`ADMIN_PASSWORD`, `HOST_AWAY_MS` — 로그인·관리자·호스트 설정. 아래 "계정과 로그인", "호스트와 관리자"를 보세요.
- `VAPID_SUBJECT` — 푸시 알림을 보낼 때 푸시 서비스에 알리는 연락처(`mailto:` 또는 `https://` 주소).

화면 공유·마이크·알림·앱 설치는 `https` 주소(또는 `localhost`)에서만 동작합니다.

**패닉(화면 보호기)**: 패닉 버튼(또는 Esc 두 번)을 누르면 화면 전체를 인강 영상 플레이어가 덮어요. 마우스를 움직이면 유튜브 컨트롤 대신 재생·정지·볼륨이 있는 일반적인 강의 플레이어 모양 컨트롤이 나오고, 소리와 마이크는 꺼져요. 풀려면 **화면을 10초 동안 눌러야** 하고(3초 남으면 남은 시간이 나타나요), 다 누르면 **비밀번호(로그인한 사람은 계정 비밀번호, 게스트는 설정에서 정한 4자리 PIN)** 를 물어요. 새로고침해도 잠금이 유지돼요. 폰은 가로 화면으로 바뀌고, 영상은 입장할 때 미리 재생해 둬요(설정에서 끌 수 있고, 영상 주소도 바꿀 수 있어요).

**쪽지 암호화**: 쪽지는 보내는 기기에서 암호화되어 서버에는 암호문만 저장돼요(서버 파일을 봐도 못 읽어요). 사진·동영상도 기기에서 암호화해서 올려요. 이 기기에서 처음 쪽지를 쓰면 쪽지 탭에서 **계정 비밀번호로 한 번 열어야** 해요. 비밀번호를 바꾸면 쪽지는 그대로 읽히지만, **비밀번호를 잊어서 관리자가 초기화하면 옛 쪽지는 읽을 수 없어요**. 푸시 알림에는 "새 쪽지가 왔어요"만 나와요. 솔직한 한계: 로그인할 때 비밀번호가 서버를 거치므로 운영자가 화면 코드를 몰래 바꾸면 가로챌 수 있고, Signal 같은 순방향 비밀성은 없어요.

**쪽지함**: 입장 화면의 "쪽지함" 버튼(옆의 "입장하기"는 방으로)을 누르면 방에 들어가지 않고 쪽지만 주고받는 쪽지함 화면이 열립니다. 방 사람들 목록에 보이지 않고 채팅·영상·음성도 받지 않으며(호스트가 될 수도 없음), 쪽지 상대 목록에는 나타납니다. 쪽지함 화면의 "방에 들어가기"로 같은 닉네임으로 방에 들어갈 수 있어요. 닉네임은 쪽지함만 쓰는 사람도 방과 똑같이 겹칠 수 없습니다.

**앱 설치 안내**: 설정 창의 "앱으로 설치"에 iPhone·iPad(Safari), Android(Chrome), 삼성 인터넷의 순서와 알림이 안 올 때의 점검이 있습니다. 쓰는 기기의 순서가 미리 펼쳐져요. 앱 이름이 바뀌면 안내 속 "시루 그룹챗"(`manifest.webmanifest`의 `short_name`)도 같이 고치세요.

## 계정과 로그인

- 방은 게스트(닉네임만)로도 들어올 수 있어요. **쪽지, 쪽지함, 푸시 알림은 로그인한 계정만** 써요. 가입하면 내 닉네임을 다른 사람이 쓰지 못해요(방에 없을 때도).
- **가입**: 닉네임 + 비밀번호(8자 이상) + 호스트가 정한 가입 코드(`SIGNUP_CODE`). 코드를 정하지 않으면 가입이 닫혀 있어요. 이메일은 쓰지 않아요.
- **로그인·가입은 `AUTH_HOST`(기본 `sirugc.kro.kr`)의 https 주소에서만** 돼요. 다른 주소(`localhost`, 집 안 IP)에서는 게스트로만 쓸 수 있어요. 프록시(NPM) 뒤라면 `TRUST_PROXY=1`이 켜져 있어야 하고, 프록시가 `X-Forwarded-Proto`와 `Host`를 넘겨야 해요. 안 그러면 서버가 https인지 몰라서 로그인이 열리지 않아요.
- 비밀번호는 `scrypt` 해시로만 저장돼요. 로그인 상태는 기기마다 무작위 토큰으로 유지하고 **3일마다 새 값으로 바뀌며**, 60일 안 쓰면 풀려요. 바뀐 뒤에도 옛 토큰은 10분만 받아 주고, 그 뒤에 쓰이면 도난으로 보고 그 기기의 로그인을 끊어요. 5번 틀리면 15분 잠겨요.
- **닉네임**은 7일에 한 번 바꿀 수 있고, 옛 닉네임은 7일 동안 다른 사람이 못 써요. 이전 닉네임은 참가자 목록과 쪽지 화면에 함께 보여요. 채팅 말풍선은 지금 닉네임으로 바뀌어요.
- **비밀번호를 잊으면** 관리자가 설정 → 계정 관리에서 임시 비밀번호를 만들어 줘요(호스트는 게스트일 수도 있어서, 남의 계정을 건드리지 못하게 관리자만 해요). 그 비밀번호로 로그인하면 바로 새로 정해야 해요.
- **계정을 삭제하면** 그 사람이 보낸 쪽지는 상대 화면에 "탈퇴한 사용자"로 남아요. 같은 이름으로 다시 가입하면 새 사람이에요.

## 호스트와 관리자

- **호스트**는 방에 맨 처음 들어온 사람이에요(게스트도 가능). 호스트가 나가거나 연결이 3분 넘게 끊기면 **가장 오래 있던 사람**이 이어받아요. 나가기 전에 참가자 탭에서 다른 사람에게 직접 넘길 수도 있어요. 대기열 조작(삭제·순서·재생·건너뛰기)과 영상 위치 이동, 강퇴·밴은 호스트만 해요. 대기열에 올리는 것은 호스트가 사람마다 허락해요(처음엔 호스트만).
- **관리자**는 `ADMIN_NAME`/`ADMIN_PASSWORD`로 만드는 계정이에요. 서버를 켤 때마다 설정 파일대로 맞춰지고, 앱 안에서는 이름도 비밀번호도 못 바꿔요. 호스트보다 위라서 호스트의 모든 일(호스트도 내보낼 수 있음)과 호스트 지정, 계정 관리(목록·임시 비밀번호·삭제·밴)를 할 수 있고, 호스트 자동 승계 순번에는 끼지 않아요. **쪽지는 읽을 수 없어요.**

## 2.0으로 올릴 때 (처음 한 번)

1. `config.env`에 `AUTH_HOST`, `SIGNUP_CODE`, `ADMIN_NAME`, `ADMIN_PASSWORD`, `TRUST_PROXY=1`(프록시가 다른 기기에 있으면 `PROXY_IP`도)을 추가하세요(`config.example.env` 참고).
2. 서버를 재시작하면 옛 `state.json`을 `state.json.bak-날짜-…`로 **백업하고 새로 시작**해요. 옛 쪽지·푸시 구독·밴 목록·호스트 키는 이어지지 않아요(알파라서). 백업 파일에는 비밀 값이 있으니 필요 없으면 지우세요.
3. 열어 둔 화면은 새로고침하고, 설치한 앱은 완전히 닫았다 다시 여세요. 알림은 로그인한 뒤에 다시 켜야 해요.
4. 관리자 닉네임으로 로그인해 보고, 가입 코드로 가입이 되는지 확인하세요.

## 접속이 자주 끊길 때

서버 콘솔에 `[연결 끊김] 이름 code=… 사유=… N초 접속` 줄이 남습니다. 읽는 법:

- `code=1006` — 중간(프록시·공유기·폰 망)에서 연결이 사라짐. 아래 프록시 설정을 확인하세요.
- `code=4001 사유=hb-silent …` / `wake-noreply` — 화면 쪽이 "보낸 신호에 답이 없다"고 보고 스스로 끊음. 연결은 서버가 아닌 중간 경로에서 멈춘 것입니다. 끊겨도 1분 안에 돌아오면 같은 자리·음성·공유를 그대로 이어받습니다.
- 폰·태블릿이 `code=1001`/`1006`으로 끊겼다면 보통 화면이 꺼진 것입니다. 정상이고, 10분 안에 돌아오면 이어져요.
- `code=4000 사유=replaced` — 새 연결로 바뀌어서 옛 연결을 닫음 (정상).

**NPM(nginx) 뒤라면** 프록시 호스트의 Advanced에 아래를 넣으세요. 기본값(60초)은 조용한 연결을 끊습니다.

```
proxy_read_timeout 3600s;
proxy_send_timeout 3600s;
```

열어 둔 탭·설치한 앱은 서버를 고쳐도 **옛 화면 그대로**입니다. 새 버전이 있으면 접속할 때 "새로고침" 안내가 뜨고, 설정 맨 아래에서 화면 버전을 볼 수 있어요. 안내가 없는 옛 화면은 한 번 새로고침(앱은 완전히 닫았다 다시 열기)해야 합니다.

```
node tools/turn-check.js      config.env에 설정한 TURN 서비스 (실제 연결)
```

`tools/*-check.js`는 Chrome이 필요합니다(`CHROME` 환경변수로 경로 지정). 임시 포트와 임시 상태 파일을 쓰므로 실제 데이터는 건드리지 않고, 소리는 꺼진 채로 돌아갑니다.

## 구조

- `server.js` — HTTP 정적 서빙 + 웹소켓(방, 호스트, 대기열, 음성/공유 신호, 밴, 끊긴 연결 이어받기)과 `/auth/*`(가입·로그인). `accounts.js` — 계정, 비밀번호, 로그인 토큰, 닉네임 예약, 관리자. `messages.js` — 쪽지와 웹 푸시. `uploads.js` — 사진·동영상 업로드와 제공.
- `public/` — `app.js`(입장·참가자·채팅) `auth.js`(로그인·가입·계정 설정·계정 관리) `layout.js`(채팅 크기 조절) `media.js`(영상·대기열·화면 공유) `voice.js` `e2ee.js`(쪽지 암호화·키 보관) `dm.js` `notify.js`(알림·위장) `panic.js`(소리 끄기·패닉) `settings.js`(테마·설정 창) `pwa.js` `sw.js`, 스타일 `style.css` `themes.css`.
- `state.json` — 계정(비밀번호 해시), 로그인 세션(토큰 해시), 차단 목록, 쪽지(암호문), 쪽지 공개 키와 비밀번호로 감싼 비밀 키, 푸시 구독, 푸시 서명 키가 저장됩니다. **비밀 값이 들어 있으니 공유하지 마세요**(git에서 제외됨). 호스트는 저장하지 않고 방 안에서만 정해져요.
